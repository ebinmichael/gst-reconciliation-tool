# Publish this project on GitHub

## 1. Create the repository

1. Sign in to GitHub and choose **New repository**.
2. Name it `gst-reconciliation-tool`.
3. Choose **Public** if you want it to be visible as a portfolio project.
4. Leave the README, `.gitignore`, and license options unchecked because this folder already includes a README and ignore file. No license has been selected; the code will be visible, but people should not assume they have permission to reuse it.
5. Select **Create repository**.

## 2. Upload the project files

1. On the new repository page, choose **Add file → Upload files**.
2. Open the local `gst-reconciliation-tool` folder and drag its files and `Template` folder into the upload area. Include `index.html`, `app.js`, `styles.css`, `instructions.html`, `README.md`, `.gitignore`, and both Excel templates inside `Template/`.
3. Use the commit message `Add GST reconciliation tool`.
4. Select **Commit changes**.

GitHub's web uploader currently supports dragging files or folders and limits each uploaded file to 25 MiB. [GitHub upload instructions](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)

## 3. Add the link to your portfolio

After the upload, copy the repository URL and add it to the Projects section of [ebinmichael.in](https://ebinmichael.in/), next to the live demo link. Describe it as source code for the GST Reconciliation Tool.

## Before uploading

- Check that the two Excel templates contain only blank/example data.
- Do not upload client workbooks, credentials, private keys, or confidential employer code.
- Decide whether you want to add an open-source license later. Without a license, the project is viewable but reuse rights are not granted.
- This cleaned-up repository differs from the current Hostinger copy; deploy the same code to Hostinger separately if you want the live site to match it.
